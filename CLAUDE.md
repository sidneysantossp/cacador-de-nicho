# Mandatory Caçadores de Nichos AI bootstrap

Before starting or modifying any owned content project, read `AI_START_HERE.md` and `docs/PRODUCTION_OPERATING_SYSTEM.md`.

The global operating contract is `factory-mode@1.1.0`. It is mandatory across projects. Project-specific Channel Brain and Production DNA may add constraints but may not silently remove the global rules.

Do not run a project from memory alone. Load the current project state and the current operating-system version before acting.
